## 1. 개요

### 1.1 해결할 문제
직원 100명 규모 제조 공장의 품질보증팀 수입검사 파트는 하루 평균 30건의 자재 로트를 검사원 2명이 종이 성적서로 검사한 뒤 엑셀로 취합한다.
그래서 (1) 몇 개를 뽑아 몇 개까지 불량이면 합격인지 검사원마다 기준이 흔들리고, (2) 어떤 협력사·부품에서 어떤 불량이 반복되는지 바로 알 수 없으며, (3) 주간 회의용 파레토 집계에 매주 3시간 이상 걸리고 협력사 피드백이 1~2주 늦어져 불량 자재가 라인에 투입된다.

> 문제 진술: 수입검사 담당자는 부품 입고 및 검사 상황에서 실시간 불량 데이터 추적 시스템의 부재 때문에 불량 자재가 생산 라인에 그대로 투입되어 발생하는 폐기 비용 및 생산 차질을 겪고 있다.

### 1.2 쓰는 사람
| 사용자 | 하는 일 | 앱에서 주로 쓰는 화면 |
|---|---|---|
| 수입검사원 (2명) | 입고 로트 샘플링 검사, 합격/불합격 판정 | 입고·검사 |
| 협력사 품질 엔지니어(SQE) | 협력사·부품별 불량 분석, 협력사에 개선 요구 | 검사 이력, 불량 파레토 |
| 품질 관리자 | 입고 자재 리스크와 협력사 품질 현황 관리, 기준정보 관리 | 협력사 등급, 기준정보 |

- 세 사용자는 **검사실 Windows PC 1대**에서 역할별 탭을 바꿔 가며 사용한다. (로그인 없음)

### 1.3 기대 효과 (KPI, 수치는 가정)
| 지표 | 현재 | 목표 |
|---|---|---|
| 주간 불량 집계·파레토 작성 시간 | 주 3시간 이상 | 주 10분 이내 |
| 반복 불량 → 협력사 피드백까지 걸리는 기간 | 1~2주 | 2일 이내 |
| 샘플 수·합격 기준의 검사원 간 차이 | 사람마다 다름 | 0건 (표준표로 자동 결정) |

### 1.4 적용할 산업공학 기법
- **계수형 샘플링 검사 KS Q ISO 2859-1** (일반 검사수준 II, 1회 샘플링): 입고수량 → 시료문자 → 샘플 수 n, 합격판정개수 Ac, 불합격판정개수 Re
- **엄격도 전환 규칙**: 보통 검사 ↔ 까다로운 검사 ↔ 검사 중지
- **파레토 분석**: 상위 불량유형 도출
- **협력사 평가**: 로트 불합격률(LRR)·ppm 기반 등급

### 1.5 완료 기준
1. 로트를 등록하면 입고수량과 부품의 AQL, 현재 엄격도로 **샘플 수와 Ac/Re가 자동으로 나온다**.
2. 불량유형별 수량을 입력하면 **합격/불합격이 자동 판정**되어 app.db에 저장된다.
3. 판정 결과에 따라 부품의 **검사 엄격도(보통/까다로운/중지)가 자동으로 바뀌고** 화면에 보인다.
4. 기간·협력사·부품을 골라 **불량유형 파레토 차트**를 볼 수 있다.
5. 기간을 고르면 **협력사별 로트 불합격률·ppm 랭킹과 등급(A~D)**이 한 화면에 나온다.
6. 프로그램을 껐다 켜도 데이터가 남아 있고, Python이 없는 다른 Windows PC에서 app.exe가 실행된다.
7. 핵심 계산은 test_logic.py의 시험 사례를 모두 통과한다.

### 1.6 이번에 만들지 않을 것
- 로그인, 사용자 권한 구분
- 네트워크 공유, 여러 PC 동시 사용, 클라우드·웹 서버
- 협력사 직접 접속, 메일 자동 발송
- 수월한 검사(reduced inspection) — 전환 점수·책임부서 승인 절차가 필요해 제외
- 2회·다회 샘플링, 특별 검사수준(S-1~S-4), 입고수량 35,001개 이상 로트
- 샘플별 개별 측정값(치수 수치) 기록과 SPC·p 관리도 — 대표 측정값·특이사항은 '비고' 칸에 글로 남긴다
- 불합격 로트의 후속 처리 결재(반품·특채·선별) — 판정 결과만 기록한다
- 안드로이드·iPad 태블릿 지원

## 3. 데이터

### 3.1 관리할 항목 [고정]
| 데이터 | 항목 |
|---|---|
| 협력사 | 협력사 코드(고유), 협력사명, 담당자, 연락처 |
| 부품 | 부품번호(고유), 부품명, 공급 협력사, AQL(0.65 / 1.0 / 1.5 / 2.5 / 4.0 중 하나), 최근 재개 일시 |
| 불량유형 | 불량유형 코드(고유), 불량유형명 (찍힘, 치수 불량, 이물, 녹, 도장 불량, 기타 등) |
| 검사원 | 검사원 이름 |
| 입고 로트 | 로트번호(고유), 부품, 입고일, 입고수량, 상태 |
| 수입검사 | 로트, 검사일시, 검사원, 적용 엄격도, 시료문자, 샘플수량 n, Ac, Re, 불량품수, 판정, 비고, 취소 여부, 취소 사유 |
| 검사 불량 내역 | 검사, 불량유형, 수량 (검사 N : M 불량유형을 연결 표로 해소) |
| AQL 시료문자표 | 입고수량 범위(최소~최대) → 시료문자, 샘플 수 (KS Q ISO 2859-1 표 1, 검사수준 II) |
| AQL 샘플링표 | (시료문자, AQL, 엄격도) → 적용 샘플 수 n, Ac, Re (표 2-A 보통, 표 2-B 까다로운, 화살표 적용 결과) |

- 관계 [고정]: 협력사 1:N 부품, 부품 1:N 로트, 로트 1:N 검사(취소되지 않은 검사는 로트당 최대 1건), 검사 1:N 검사불량내역, 불량유형 1:N 검사불량내역, 검사원 1:N 검사
- 협력사명·부품명은 각자의 표에만 저장하고 다른 표에는 코드(외래키)만 둔다.
- 검사 표의 엄격도·시료문자·n·Ac·Re는 **검사 당시 판정 근거를 보존하기 위한 이력 값**으로 저장한다. (이후 부품 AQL이나 엄격도가 바뀌어도 과거 판정이 바뀌지 않게)

### 3.2 입력 규칙 [고정]
1. 로트번호, 협력사 코드, 부품번호, 불량유형 코드는 중복될 수 없다.
2. 입고수량은 **2 이상 35,000 이하**의 정수다. (시료문자 A~M 범위)
3. 샘플수량은 사람이 입력하지 않고 AQL 표에서 자동으로 정한다. 샘플 수가 입고수량 이상이면 **전수검사**(n = 입고수량)로 한다.
4. 불량유형별 수량은 0 이상의 정수다. 불량품 1개는 대표 불량유형 1개로만 기록하므로 **불량품수 = 불량유형별 수량의 합**이고, **불량품수 ≤ 샘플수량**이어야 한다. 어기면 저장하지 않고 안내한다.
5. 입고일·검사일은 미래 날짜일 수 없고, 검사일은 입고일보다 빠를 수 없다.
6. 검사 입력은 상태가 '대기'인 로트에만 할 수 있다.
7. 부품의 엄격도가 **'중지'이면 그 부품의 새 로트는 검사할 수 없다.** 관리자가 '재개'해야 다시 검사할 수 있다.
8. 판정 취소에는 **사유가 반드시 있어야** 한다.

### 3.3 상태가 바뀌는 순서 [고정]

**(1) 로트 상태**
```
대기 ──(검사 입력, 판정=합격)──▶ 합격
   └──(검사 입력, 판정=불합격)──▶ 불합격
합격/불합격 ──(판정 취소, 사유 필수)──▶ 대기
```
- 로트 등록 시 상태는 항상 '대기'. 합격 ↔ 불합격으로 직접 바꿀 수 없다. (반드시 취소 후 재검사)
- 취소된 검사는 지우지 않고 '취소' 표시와 사유를 남긴다. 취소된 검사는 모든 계산(판정 집계, 엄격도 전환, 파레토, 등급)에서 제외한다.
- 불합격 로트를 선별·재작업하거나 협력사가 다시 납품하면 **새 로트번호로 등록**한다. 원래 로트는 불합격으로 남는다.

**(2) 부품별 검사 엄격도 (KS Q ISO 2859-1 전환 규칙)**
```
        (연속 5로트 이내에서 2로트 불합격)
 보통 ─────────────────────────────▶ 까다로운
  ▲                                     │
  └──────(연속 5로트 합격)───────────────┤
                                        │ (까다로운 검사 중 불합격 누계 5로트)
                                        ▼
                                       중지 ──(관리자 '재개')──▶ 까다로운
```
- 새 부품의 처음 엄격도는 '보통'이다.
- 엄격도는 그 부품의 취소되지 않은 검사를 검사일시 순서로 처음부터 다시 계산해서 정한다. (저장값이 아니라 이력으로 계산)
- '재개'하면 재개 일시 이후 검사만으로 계산하고, 시작 상태는 '까다로운'이다.

### 3.4 계산 규칙 [고정]
| No | 규칙 | 식 |
|---|---|---|
| C1 | 시료문자 | 입고수량이 속한 범위의 시료문자 (검사수준 II): 2~8 A, 9~15 B, 16~25 C, 26~50 D, 51~90 E, 91~150 F, 151~280 G, 281~500 H, 501~1,200 J, 1,201~3,200 K, 3,201~10,000 L, 10,001~35,000 M |
| C2 | 샘플링 계획 | (시료문자, AQL, 엄격도)로 AQL 샘플링표에서 n, Ac, Re를 찾는다. 표의 화살표(↓ 아래 첫 계획, ↑ 위 첫 계획)는 표를 만들 때 이미 적용해 둔다. n ≥ 입고수량이면 n = 입고수량(전수검사) |
| C3 | 합부 판정 | 불량품수 ≤ Ac 이면 **합격**, 불량품수 ≥ Re 이면 **불합격** |
| C4 | 엄격도 전환 | 3.3 (2)의 규칙 |
| C5 | 기간 불량률 | Σ불량품수 ÷ Σ샘플수량 (로트 불량률의 평균이 아님) |
| C6 | ppm | 기간 불량률 × 1,000,000, 정수로 반올림 |
| C7 | 로트 불합격률(LRR) | 불합격 로트 수 ÷ 검사 완료 로트 수 (대기·취소 제외) |
| C8 | 협력사 등급 | 기간 LRR 기준 — A: 2% 이하, B: 2% 초과 5% 이하, C: 5% 초과 10% 이하, D: 10% 초과. 검사 완료 로트가 5건 미만이면 **'평가 보류'** |
| C9 | 협력사 랭킹 | LRR 높은 순 → 같으면 ppm 높은 순 → 같으면 협력사명 가나다순 ('평가 보류'는 맨 아래) |
| C10 | 파레토 | 불량유형별 수량 내림차순(같으면 유형명 가나다순), '기타'는 맨 오른쪽. 누적 비율 = 누적 수량 ÷ 전체 불량 수량, 80% 기준선 표시 |
| C11 | 표시 | 비율은 계산할 때 소수(0~1), 화면에 보일 때만 %(소수 둘째 자리) |

> 근거 표: 보통 검사(표 2-A) 값은 공개된 MIL-STD-105E 전사본(ISO 2859-1과 동일 계열)과 대조했다. 까다로운 검사(표 2-B)는 "보통 검사표에서 AQL을 한 단계 엄격하게 옮긴 위치 + 까다로운 검사 Ac 계열(0,1,2,3,5,8,12,18)" 규칙으로 만들었으므로 **제출 전 KS Q ISO 2859-1 원문 표 2-B와 대조 확인이 필요하다.**

| 화면(탭) | 역할 | 주 사용자 |
|---|---|---|
| ① 입고·검사 | 로트 등록(다음 로트번호 자동 제안), 대기 로트 목록, 샘플링 계획(n, Ac, Re, 엄격도) 표시, 불량 입력 → 저장 전 확인창 → 판정 | 검사원 |
| ② 검사 이력 | 조건 검색, 결과 목록, 판정 취소 | SQE, 관리자 |
| ③ 불량 파레토 | 기간·협력사·부품 선택 → 파레토 차트 | SQE |
| ④ 협력사 등급 | 기간 선택(기본 최근 3개월) → 협력사 랭킹 표와 등급, 부품별 엄격도 현황 | 관리자 |
| ⑤ 기준정보 | 협력사·부품(AQL)·불량유형·검사원 등록, 중지 부품 재개 | 관리자 |

### 주요 업무 흐름에 따른 화면 이동
1. **검사원**: ① 로트 등록 → 대기 목록에서 로트 선택 → 표시된 샘플 수만큼 뽑아 검사 → 불량 수량 입력 → 저장(판정과 엄격도 변화 표시)
2. **SQE**: ② 불합격 로트 확인 → ③ 해당 협력사·부품의 상위 불량 확인 → 협력사에 피드백
3. **품질 관리자**: ④ C·D 등급 협력사와 '까다로운/중지' 부품 확인 → ② 해당 로트 확인 → (개선 확인 후) ⑤ 재개

> 화면 배치, 색, 버튼 위치, 문구는 [고정]이 아니며 코드 생성 단계(3-8)에서 대화로 다듬는다.

## 5. 기술 조건 [고정]
- Python + SQLite + Tkinter(차트는 matplotlib), 클라우드·웹 서버·외부 DB 사용 금지, 인터넷 없이 동작
- DB 파일은 exe 밖, exe와 같은 폴더의 `data/app.db`. 경로는 exe 위치 기준. 파일이 없으면 첫 실행 때 테이블과 AQL 기준표를 새로 만든다.
- 최종 결과물: PyInstaller로 만든 app.exe (실행 시 검은 콘솔 창 없음)
